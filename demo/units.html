toPx()

One of every unit this browser resolves. A unit it rejects has no entry, so this doubles as a support map. Browsers quantise computed lengths, so scaling one of these up drifts from measuring that size directly — the line below the grid shows by how much.

toPx().percent

A percentage is not a unit, so there is one value per property rather than one value. Note which of these matches which.
